# Plastisphere-Metagenome

This directory contains scripts related to the manuscript "Viruses as a Double-Edged Sword: Drivers and Constraints in the Prevalence and Evolution of Antibiotic Resistant Bacteria and Pathogens in the Plastisphere".

The scripts of metagenomic analysis  (Platisphere analysis pipeline.sh) and statistical analysis (00-08.R) are placed in this directory.
