# Plastisphere-Metagenome

This directory contains scripts related to the manuscript "Viruses as a Double-Edged Sword: Drivers and Deterrent in the Prevalence and Evolution of Antibiotic Resistant Bacteria and Pathogens in Aquatic Plastispheres".

The scripts of metagenomic analysis  (00.Platisphere_analysis_pipeline.sh) and statistical analysis (01-09.R) are placed in this directory.
